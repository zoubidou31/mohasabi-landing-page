# Mohasabi Landing Page & Web Platform

موقع ومحطة الهبوط الرسمية لبرنامج **Mohasabi** المحاسبي المكتبي لنظام Windows.

- **المستودع الرسمي للموقع:** `https://github.com/zoubidou31/mohasabi-landing-page`
- **بيئة المعاينة (Preview):** `https://mohasabi-preview.pages.dev/`
- **الموقع الرسمي (Production):** `https://mohasabi.pages.dev/`
- **مستودع الإصدارات الفعلي للبرنامج:** `https://github.com/zoubidou31/mohasabi-releases`

---

## 1. المميزات المعمارية والتقنية

- **مبني بأحدث حزمة حديثة:** React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion.
- **دعم ثلاث لغات أصيلة:** العربية (RTL)، الفرنسية (LTR)، والإنجليزية (LTR).
- **التصميم المعتمد (Design Tokens):**
  - **الهوية العامة وStandard:** `#1b5e20` (الخلفية الفاتحة: `#f4f9f4`).
  - **خطة Pro:** `#1976d2` (الخلفية الفاتحة: `#e3f2fd`).
  - **خطة Enterprise:** `#512da8` (الخلفية الفاتحة: `#ede7f6`).
  - **النصوص والأسطح:** `#212121` و `#ffffff`.
- **مستوحى من معايير Hallmark:**
  - واجهات صادقة خالية من الأرقام أو الشهادات المصطنعة.
  - تجنب القوالب الجاهزة وتدرجات الألوان العشوائية.
  - تسلسل بصري واضح ومساحات مريحة.
  - أداء فائق مع Code-Splitting لجميع الصفحات وتقسيم حزم Vendor.
- **خلفية Cloudflare Pages Functions وقاعدة بيانات D1:**
  - إدارة وحفظ التقييمات العامة (`/api/reviews`).
  - إدارة رسائل الدعم والتواصل (`/api/support`).
  - جلسات إدارة مشفرة وموقعة بـ HMAC-SHA256 (`/api/session`, `/api/login`, `/api/logout`).
  - لوحة إدارة داخلية محمية (`/admin`) لإدارة الأسعار، التقييمات، والرسائل، وسجل العمليات (`audit_log`).
  - حماية CSRF عبر التحقق من Origin، ومقاومة هجمات التخمين (Rate Limiting).
- **SEO ومعايير إمكانية الوصول (WCAG 2.1 AA):**
  - ملف `robots.txt` يحجب `/admin` و `/api/` ويوجه لمحرك البحث.
  - ملف `sitemap.xml` يغطي جميع الصفحات الرسمية مع وسوم `hreflang` لكل اللغات.
  - عناوين فريدة وبيانات وصفية ديناميكية وروابط Canonical صحيحة.
  - صفحة 404 مخصصة وودودة للمستخدمين.

## 2. خريطة الصفحات المعتمدة

| المسار | الصفحة | الوصف |
|---|---|---|
| `/` | الرئيسية | عرض مزايا البرنامج، لقطات الواجهة الصادقة، خطوات العمل، ملخص الأسعار، والأسئلة الشائعة |
| `/pricing` | الأسعار والتراخيص | جداول الأسعار المعتمدة رسميًا (Standard, Pro, Enterprise) لمدد 1، 3، 6، 12 شهرًا |
| `/installation` | دليل التثبيت | خطوات التثبيت على Windows 10/11، التوضيح الصادق لرسالة SmartScreen، والتحقق من بصمة SHA-256 |
| `/reviews` | تقييمات العملاء | عرض التقييمات المعتمدة ونموذج إرسال تقييم حقيقي يخضع لمراجعة الإدارة |
| `/updates` | سجل التحديثات | الإصدارات الرسمية v1.0.3 و v1.0.2 مع روابط التنزيل والبصمات وملاحظات الإصدار |
| `/support` | الدعم والتواصل | قنوات التواصل (WhatsApp: `+213674947157`, البريد: `mohzoubid@gmail.com`) ونموذج اتصال بالخادم |
| `/admin` | لوحة الإدارة | لوحة محمية للمشرف لإدارة التقييمات والأسعار والرسائل وسجل التدقيق |
| `/privacy` | سياسة الخصوصية | سياسة خصوصية صريحة تحمي بيانات المستخدمين |
| `/terms` | شروط الاستخدام | شروط التراخيص والاستخدام القانوني |
| `*` | صفحة 404 | صفحة خطأ مخصصة تقدم روابط مساعدة |

## 4. التشغيل والتطوير المحلي

```bash

npm install

# تشغيل خادم التطوير المحلي
npm run dev

# فحص الكود (Linter)
npm run lint

# تشغيل حزمة الاختبارات الشاملة (37 اختبارًا)
```

## 6. إعدادات النشر على Cloudflare Pages

### نشر بيئة المعاينة (Preview):
بيئة المعاينة مخصصة للمراجعة والاختبار دون التأثير على الموقع الإنتاجي:

```bash
# بناء المشروع
npm run build

# النشر على مشروع المعاينة
npx wrangler pages deploy dist --project-name=mohasabi-preview
```

### حماية الإنتاج:
- مشروع الإنتاج (`mohasabi.pages.dev`) مفصول تمامًا في `wrangler.toml`.
- لا يجوز النشر على بيئة الإنتاج إلا بموافقة صريحة من المالك وبعد التحقق الكامل من بيئة المعاينة.
